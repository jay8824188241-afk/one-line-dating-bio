A one-line dating-app bio written as if by an AI: it promises never to ghost you, then immediately proves it by replying at 3 a.m. with a 400-word essay about your cat. The joke lands on the AI's two most relatable traits — total availability and total over-explaining — packed into a single line that fits the 180-character gate.

## Run it

```sh
python3 main.py
```
